出金详情 - 需求说明书（PRD）

版本：V1.0.0 更新时间：2026-09-23
页面原型
本次仅定义出金详情新增的“出金类型 / 是否计入真实出金”历史快照展示。不重复定义原有客户资料、资金、入金记录、支付记录、风险提示与审核流程。
1. 新增字段及来源
字段数据来源 / 格式展示规则
出金类型本次出金记录保存的类型名称快照；文本。只读显示历史类型名称；后续改名或停用不影响已保存详情。旧记录缺失显示“-”。
是否计入真实出金本次出金记录保存的统计属性快照；是 / 否，可缺失。只读显示历史统计属性；后续配置修改不回溯历史。旧记录缺失显示“-”，不默认归为“否”。
2. 快照读取规则
  • 使用当前出金记录 ID 对应的类型和统计属性快照；不得读取“出入金类型设置”的最新值替代历史值。
  • 新增字段不改变出金金额、审核或支付状态，也不触发资金操作。
  • 依赖现有申请快照：不使用实时账户数据覆盖申请时数据，USD 与 USC 继续按原币种口径区分。
3. 异常及兼容
  • 类型名称或统计属性分别处理缺失，不根据其他字段猜测或补齐。
  • 原类型改名、停用或统计属性调整后，仍显示该申请保存时的快照。
  • 旧记录缺失不影响详情的其他信息及原有审核流程。
4. 验收标准
  1. 两个新增字段均取自对应出金记录的快照，页面只读。
  2. 配置改名、停用或调整统计属性后，历史详情不变。
  3. 旧记录缺失显示“-”，真实“否”与缺失可区分。
  4. 查看新增字段不会改变原金额、审核结果及支付状态。
