通知配置 - PRD

1. 页面名称

风控管理 → Lark 通知 → 通知配置。

2. 页面目的

为现有10条业务通知规则选择接收群组及启用状态，不实现真实自动检测。

3. 页面功能

  • 保留通知名称、说明、通知群组、状态、设置的列表结构。
  • 设置弹窗支持多群组和启用/停用；名称、顺序及说明固定不变。

4. 核心字段定义

String[] 为去重的群组标识数组，名称仅作展示；空数组为 []。DateTime 展示 YYYY-MM-DD HH:mm:ss（19字符），原型取本机时间，正式使用 CRM 统一时区。缺失值显示“—”。所有发送结果均为本地演示，不接 Lark API 或真实业务事件。

通知说明 / 触发条件什么业务情况下通知现有规则说明String非空；沿用原说明无预置说明是，预置否仅展示，不实现算法、阈值或定时任务。

5. 核心业务规则

  • 仅启用群组可选择，保存时再次核对。停用或删除群组会从所有通知规则和 CRM 登录通知配置中移除；重新启用不自动恢复选择。
  • 群组改名只更新当前配置显示，不修改历史通知的群名称快照。无有效群组允许保存，但不产生真实投递。
  • 旧个人接收人配置无法推断对应群组，不自动转换；旧本地数据保留，新配置须重新选择群组。
  • 本次不增加通知级别、模板或复杂触发设置。规则名称和说明中既有的业务负责人描述保持不变，实际接收目标统一由群组配置决定。

6. 操作说明

设置回填当前群组及开关，取消放弃草稿；保存仅更新本条规则。未配置群组给出说明，允许保存空名单。保存失败需提示仅会话生效，不冒充持久化成功。

7. 状态说明

规则：启用 / 停用。群组：启用 / 停用；删除后不可选。启用但未配置群组不等同发送成功。

8. 验收标准

  1. 10条规则与现有名称、顺序、说明完全一致。
  2. 可多选启用群组、保存后列表更新且刷新保持。
  3. 停用群不可选，停用/删除联动移除，重新启用不自动勾选。
  4. 规则开关可保存；停用不生成模拟记录，历史记录不变。
