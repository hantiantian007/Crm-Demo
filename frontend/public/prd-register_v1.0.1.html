业务流程

仅展示新增留资入口及信息来源字段相关流程；不重复原注册流程。保存失败提示及重试方式正文尚未明确，标为待确认。 窄屏可在图内横向滚动查看。

本期需求重点 (致产研测)

  • 增加客户留资入口： 本次版本主要在原有注册流程基础上，仅新增了针对无推荐码客户的“留资入口”（即点击申请账号弹出的收集表单），其他注册逻辑保持不变。
  • 留资表单新增字段： 在留资申请表单中，新增必填字段“信息来源”，选项包含：“官网访问”、“社交平台”、“客户推荐”、“线上活动”、“线下金融活动”、“金融资讯网站”、“其他渠道”。该字段位置位于电子邮箱正下方。

1. 新增留资入口及依赖

依赖原注册规则：用户注册必须填写推荐码（绑定上级代理/推荐人）。若无推荐码，需通过“申请账号”进入留资流程，由后台市场人员介入分配。

2. 新增入口交互

推荐码下方增加“无邀请码，请点击此处：申请账号”。“申请账号”为品牌黄色可点击文字，打开留资申请弹窗；不修改原注册字段、校验及提交逻辑。

3. 【留下资料】留资弹窗

1. 点击“无邀请码，请点击此处：申请账号”触发弹窗。

2. 弹窗文案提示：“信息提交后，我们的顾问会在2个工作日内与您联系”。

3. 成功提交后关闭当前弹窗，弹出新的提示窗：“您的资料已提交，请注意邮箱信息”。

字段名称 是否必填 限制规则 逻辑说明
姓名 是 无 标准文本输入框。
联系电话 是 仅限数字 输入失去焦点时校验，不允许输入非数字字符。
电子邮箱 是 标准邮箱格式 失去焦点时校验邮箱格式。
信息来源 是 ["请选择", "官网访问", "社交平台", "客户推荐", "线上活动", "线下金融活动", "金融资讯网站", "其他渠道"] 下拉单选框，提交时若未选择则提示必填。
咨询内容 否 ["请选择", "成为代理", "政策了解", "个人交易", "其他"] 下拉单选框。
微信 否 文本输入框 非必填。
WhatsApp 否 文本输入框 非必填。
其他联系方式 否 文本输入框 非必填。
验证码 是 4位英数混合图形验证码 点击图片可刷新。
取消/提交按钮 - - 点击【提交】后校验必填项，校验通过后弹出成功提示：“您的资料已提交，请注意邮箱信息”，并将留资数据写入 Crm-Group 后台留资列表。
