CRM 密码安全与风险触发强制重置

目标：在账户存在风险时，要求用户在下次登录完成改密；改密完成前全局阻断 CRM 业务访问，提升账户安全。

生效规则与阻断

  • 强制改密生效：下次登录 或 指定时间。
  • 全局阻断：未完成改密前，不可访问 CRM 业务页面与功能，仅允许登录、验证码与改密交互。

强制改密覆盖范围（V1.0.1）

条件 要求
账号类型 标准账号
业务身份 代理、直客
说明 不支持系统账号、不支持“其他”身份进入范围强制。

配置字段与状态

  • 配置字段：配置标题、适用范围（固定：标准账号·代理/直客）、生效时间、用户提示、预计影响客户数量。
  • 用户提示：管理员必填，用于说明用户为何需要改密；若旧记录缺失则使用默认文案：为保护您的账户安全，请完成密码修改后继续使用 CRM。
  • 状态：未生效（pending）/ 生效中（active）/ 已完成（completed）/ 已停用（disabled）。
  • 多配置并行：新配置不覆盖旧配置，可同时生效；命中多条仅生成一次拦截但需展示命中策略信息。

管理员操作流程

  • 新增规则：在“配置记录列表”点击新增规则，填写配置标题、用户提示、生效时间并提交。
  • 生效机制：下次登录为立即生效；指定时间到达后生效（演示按时间判断）。
  • 停用配置：已停用仅允许查看，不可修改。

指定账号强制改密（独立流程）

  • 支持搜索选择多个账号一次性提交生成批次记录（批次 ID）。
  • 批次可终止：仅“生效中/部分完成”可终止；终止需记录操作人、时间与原因；不回滚已完成改密。

邮箱验证码（演示）

  • 有效期：10 分钟；发送冷却：60 秒；失败次数：5 次后进入限制状态。
  • 演示阶段不接入真实邮箱服务，但交互与状态变化保持完整。
