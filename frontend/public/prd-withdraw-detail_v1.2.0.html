3. 风险等级判定规则

3.1 风险等级定义

等级判断标准
低风险风险数据完整可靠，未命中任何有效风险规则。
中风险命中至少一类有效风险，但不满足高风险组合条件。
高风险同时命中至少两类相互独立的有效风险，且至少包含“近期收款账户变更”或“高风险关联账户”。
待核实风险数据缺失、申请/客户关联不明确或读取失败，无法可靠完成评估；优先于其他等级，不以部分命中或空列表认定低风险。

3.2 基础风险规则

风险类型触发条件与数据来源单独命中
近期收款账户变更出金申请前 48 小时内修改钱包或银行卡；读取对应客户的收款账户变更记录，以申请时间为参照。中风险
近期身份信息变更出金申请前 24 小时内修改手机号、邮箱或密码；读取对应客户安全信息变更记录，不展示密码或验证码。中风险
高风险关联账户已有有效关联依据，且关联账户已命中风险；读取已有账户关联及有效风险事件。中风险
异常登录或设备变化存在与本次出金相关的异常登录安全事件；读取已关联的登录/设备安全事件，不把任意设备变化直接认定为风险。中风险

48 小时和 24 小时沿用建议窗口，正式生产阈值仍需业务确认；时间边界、业务时区及有效关联口径沿用已确认规则，未确认项不得自行补造。

3.3 组合计算与去重

先验证数据可靠性，再识别有效命中并按上述四类风险去重。设 S 为有效风险类别集合，N = S 的类别数：

  • 数据不可靠 → 待核实，命中总数显示“—”，不得自动视为无风险。
  • 数据可靠且 N = 0 → 低风险。
  • 数据可靠且 N ≥ 2，且 S 包含“近期收款账户变更”或“高风险关联账户” → 高风险。
  • 数据可靠且 N ≥ 1，但不满足上述高风险组合 → 中风险。
  • 同一类别重复事件不增加独立类别数；“多项风险同时命中”是组合判定条件，不作为第五类独立风险计数。
  • 不能仅凭出金金额较大判定高风险。等级仅用于提示和查看依据，不自动拒绝、冻结或放行出金。

3.4 判定示例

条件结果
仅修改收款银行卡（含同类多次修改）中风险
修改收款银行卡 + 异常登录高风险
高风险关联账户 + 近期修改邮箱高风险
仅异常登录中风险
身份信息变更 + 异常登录中风险
数据完整且无有效命中低风险
数据无法可靠获取待核实

4. 三种风险数据状态及边界

状态右侧摘要弹窗表现
风险命中展示对应等级、命中数量。展示同一申请命中记录、可用依据及按时间排序的关联事件。
未命中风险显示“未发现已知风险”，命中数量为 0。展示未命中说明及已确认的申请事件，不为展示效果编造风险。
风险评估不可用显示“风险评估不可用”，等级待核实，数量“—”。说明数据尚未取得或申请关联不完整；不展示其他客户风险，不自动判为无风险。

保留固定演示场景：9900456 为命中；8100453 为未命中及已确认申请事件；8110474 为风险关联不可用。风险展示仅在客户、MT账号和当前申请关联明确时使用对应数据。本次不修复或重构原账户路由逻辑，也不通过默认客户补齐风险数据。

5. 验收标准

  1. 等级判定覆盖上述七个示例；同类重复命中不升级，多项命中不重复计数，金额较大不单独判高风险；不可用始终待核实。本次验证 PRD 规则完整性，不代表真实计算已接入。
  2. 右侧摘要展示等级、命中数量，指定辅助文案已移除，按钮保留。
  3. 点击“查看风险明细”打开当前页面弹窗，路由不变；关闭后可再次打开。
  4. 弹窗摘要与右侧卡片、命中明细一致，不串用其他申请的数据。
  5. 风险依据支持逐条展开/收起；缺失时明确显示“暂无可用依据”。
  6. 风险时间线按实际事件时间排序，与明细共用数据，不与审核时间线混合。
  7. 命中、未命中、不可用三种场景均可展示，不可用不显示无风险或默认低风险。
  8. 关闭弹窗后原有出金审核功能不受影响；不发生自动资金或审核操作。
