【页面 PRD】客户变动明细

查看原型
本文档记录了客户变动明细页面增加关系树查询、筛选条件扩充以及列表新增字段的业务需求。
1. 页面目标
目标在原有明细页的基础上，方便管理员和业务员通过代理线向下穿透，精准追溯和排查客户信息或底层配置的变更记录。
涉及页面/crm/change-detail
2. 新增/调整需求
需求项说明
左侧增加关系树查询页面左侧接入标准 CRM 代理关系树组件。点击树状节点，右侧列表自动加载对应节点及其伞下成员的变动记录。
新增 MT 账号查询搜索区域新增 MT账号 筛选条件，支持按 MT 账号精准查询变动记录。
操作者筛选新增 操作者 输入框，支持输入操作者邮箱进行查询，快速追溯某个后台管理员或业务员账号的所有修改动作。
新增处理时间筛选新增 处理时间 筛选条件，支持起止时间段过滤。需明确：1、时间格式为“年月日至年月日”；2、统一采用“北京时间”。精确追溯变更发生的具体时间。
列表新增“变更类型”字段数据列表中，紧跟“客户信息”列之后新增此列。对底层的变更操作进行更高维度的宏观分类（如：基础资料变更、佣金变更、敏感数据变更）。
3. 数据口径
基础资料变更针对客户基本信息的调整，如真实姓名、邮箱、联系方式修改等。
佣金变更针对客户交易成本相关的调整，如返佣配置、点差加点、代理分组变更等。
敏感数据变更涉及高权限或资金安全的底层配置调整，如信用额度调整、特殊风控参数修改等。
4. 测试重点
1. 左侧点击关系树节点，右侧列表及分页是否能正确联动过滤。
2. 搜索栏输入 MT 账号、操作者等条件，是否能精准过滤出对应的变更流水。
3. 列表是否正确展示“变更类型”列，枚举值归类是否准确。
4. 表单内的“处理时间”样式是否显示正常且不会超出或挤压其他搜索条件。
