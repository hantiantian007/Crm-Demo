Lark 群组管理 - PRD

1. 本次调整目的

维护 Lark 群名称及其自定义机器人 Webhook，供业务规则和 CRM 登录通知选择。群组替代个人 ID 绑定，不再维护 CRM 管理人员与 Lark User ID 的关系。

2. 新增/调整内容

  • 普通表格展示群组名称、说明、脱敏 Webhook、状态、更新时间和操作。
  • 新增、编辑、启用/停用、确认删除；仅配置演示数据，不验证 Webhook 真实有效性。

3. 核心字段定义

String[] 为去重的群组标识数组，名称仅作展示；空数组为 []。DateTime 展示 YYYY-MM-DD HH:mm:ss（19字符），原型取本机时间，正式使用 CRM 统一时区。缺失值显示“—”。所有发送结果均为本地演示，不接 Lark API 或真实业务事件。

字段名称字段含义数据来源数据类型字符/格式要求状态/枚举默认值是否必填是否可编辑业务规则 / 何时变化
群组 ID群组配置稳定唯一标识新增时系统生成String非空；示例 group-时间戳-随机值无系统生成是，系统否通知配置保存 ID，不用名称作为关联键；删除不复用该 ID。
群组名称管理员辨认接收目标的名称管理员手动填写String去除首尾空格，1～80字符，同名不重复无新增为空是是改名同步展示于当前配置，历史群名称快照保留。
群组说明群用途与通知职责管理员手动填写String去除首尾空格，0～300字符，可空无空字符串否是只说明用途，不创建通知规则。
Webhook 地址目标 Lark 群自定义机器人的接收地址管理员从对应国际版 Lark 群的自定义机器人设置中获取后填写String1～2048字符；HTTPS；域名 open.larksuite.com；路径 /open-apis/bot/v2/hook/…；不含账号密码、查询串或片段非状态字段新增为空；示例为 demo-* 无效地址是是，仅新增/编辑弹窗只校验基本格式，不验证真实有效性。列表只显示固定脱敏文本，title等属性也不得泄露地址；编辑输入默认遮蔽。
启用状态该群是否可作为接收目标管理员设置Booleantrue / false，不可空启用 / 停用新增 true；预置状态沿用是是停用不删除历史，只从当前规则/登录通知配置移除。
更新时间最近一次成功修改群组的时间系统自动生成DateTimeYYYY-MM-DD HH:mm:ss，19字符无新增时刻是，系统否保存或启用/停用时更新；取消/校验失败不更新。
操作可用管理入口系统生成UI操作集合新增、编辑、启用/停用、删除按状态显示对应操作按当前群状态系统提供否停用和删除需确认；删除不可恢复，只可重新新增配置。

4. 核心业务规则

  • 仅启用群组可选择，保存时再次核对。停用或删除群组会从所有通知规则和 CRM 登录通知配置中移除；重新启用不自动恢复选择。
  • 群组改名只更新当前配置显示，不修改历史通知的群名称快照。无有效群组允许保存，但不产生真实投递。
  • 旧个人接收人配置无法推断对应群组，不自动转换；旧本地数据保留，新配置须重新选择群组。
  • 群 Webhook 与个人 open_id、邮箱或手机号不是同一概念，本方案不查询或保存个人 ID。
  • 仅使用国际版 Lark（Lark Suite），不是中国大陆版飞书；国际版接口域名为 open.larksuite.com，不得调用 open.feishu.cn。
  • 前端样例地址没有真实投递能力，请勿将真实 Webhook 输入演示环境。正式开发时 Webhook 及其他敏感信息必须由后端安全保存，不写入前端代码、浏览器存储、通知记录或日志；前端只接收脱敏值。
  • 本阶段不发网络请求、不获取 token、不调用 Lark API，不把格式通过当成地址有效。

5. 操作说明

新增/编辑弹窗填写名称、说明、Webhook 和开关；保存后列表更新，取消不变。重名、空名称、空/格式错误地址显示校验提示。停用/删除确认时说明影响通知规则和登录通知，确认后执行；历史通知不删除。开启/关闭都不发送消息。

6. 状态说明

启用：可被配置选择，并不表示已验证或已发送。停用：不能被选择。删除：移除群配置及当前引用，不新增“已删除”表格状态。格式校验失败保持原数据。存储失败显示仅会话生效。

7. 验收标准

  1. 群组增改、启停、删除及取消行为正常，刷新后配置保持。
  2. 列表 Webhook 脱敏，无完整地址 tooltip；只有编辑弹窗可显式查看草稿。
  3. 启用群组可多选，停用/删除同步移除两处引用，历史记录保留。
  4. 未调用 Lark、未发送任何真实消息，不再提供个人 ID 绑定。
  5. 文档入口均为国际版 Lark，明确正式凭证后端保存。
