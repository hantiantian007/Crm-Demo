客户注册资料 - 需求说明书 (PRD)

所属模块：其他页面 | 更新日期：2026-09-20 | 当前版本：V1.0.0

一、页面用途与范围

  • 用于客户开户注册过程中的资料填写与身份信息提交，形成可追溯的资料记录。
  • 本 PRD 聚焦于页面字段定义、交互流程、提交校验与验收标准。

二、页面与入口

项 说明
页面路由 /other/customer-register-profile
菜单入口 左侧菜单：其他页面 / 客户注册资料
PRD 入口 页面顶部 PRD 按钮通过右侧 Drawer 打开。

三、页面结构与布局

  • 顶部信息区展示客户头像与邮箱。
  • 内容区包含两个 Tab：用户资料、账号安全。
  • 页面采用窄版单列布局，字段按顺序纵向填写；证件正反面上传入口在单列内并排。

四、本次页面调整对照表

调整项 修改前 修改后 说明
地区字段 地区 注册地区（7 个固定选项） 代表申请开户的地区，不等同于常住地区。
居住地字段 居住地（自由输入） 常住国家/地区（必填下拉） 选项范围不局限于 7 个注册地区。
地址补充字段 无 省/州、城市、详细居住地址（选填） 用于完善常住地址信息。
页面布局 多列/宽版展示 窄版单列纵向填写 提高填写可读性与一致性。

五、注册资料字段定义

1. 字段清单

字段 类型 必填 规则与说明
注册地区 下拉 是 提示语：请选择申请开户的地区。选项固定：越南、中国、中国香港、韩国、日本、泰国、新加坡。
手机号 区号下拉 + 输入框 是 区号与手机号均必填。
真实姓名 输入框 是 用于客户身份信息记录与核验。
出生日期 日期 是 选择客户出生日期。
证件类型 下拉 是 选项示例：护照、身份证 / ID。
证件号 输入框 是 记录证件号码。
证件照片（正面） 上传 是 证件正面照片。
证件照片（反面） 上传 是 证件反面照片。
常住国家/地区 下拉 是 选项范围覆盖常见国家/地区，不限定为注册地区选项集合。
省/州 输入框 否 用于补充常住地址信息。
城市 输入框 否 用于补充常住地址信息。
详细居住地址 输入框 否 用于补充常住地址信息。

2. 地址字段口径说明

字段 含义 选项来源/规则 必填 保存内容与示例
注册地区 客户申请开户的地区选择 固定 7 项；不随常住地址变更而变化。 是 保存选择值（如：中国香港）。
常住国家/地区 客户当前长期居住的国家/地区 下拉选项覆盖常见国家/地区；选项集合不限制为注册地区 7 项。 是 保存选择值（如：加拿大）。
省/州 常住地址的省/州/行政区 客户选填输入。 否 示例：Ontario / 广东省。
城市 常住地址的城市 客户选填输入。 否 示例：Toronto / 深圳。
详细居住地址 街道、门牌、楼层等详细信息 客户选填输入。 否 示例：No. 88, Queen St. / XX路88号X座。
重要说明
  • 注册地区与常住国家/地区为两个独立字段，值可以不同，不得互相覆盖。
  • 客户填写的地址信息不等于实际使用地区；注册 IP、后续登录地区不属于本表单字段。

六、提交校验与错误提示

  • 提交按钮位于表单底部，提交前对必填字段进行校验。
  • 必填项：注册地区、常住国家/地区、手机号（区号+号码）、真实姓名、出生日期、证件类型、证件号、证件照片（正/反）。
  • 错误提示需明确指向缺失项，例如：请先选择注册地区 / 请先选择常住国家/地区。

七、验收标准

  • 可通过菜单进入页面，并正常展示用户资料/账号安全 Tab。
  • 页面为窄版单列布局，字段纵向填写；证件正/反面上传入口并排。
  • 注册地区字段显示 7 个固定选项，且提示语为“请选择申请开户的地区”。
  • 常住国家/地区为必填下拉，选项范围不限制为 7 个注册地区。
  • 提交校验覆盖全部必填项，错误提示明确指向具体字段。
  • 注册地区与常住国家/地区可选择不同值，且系统不互相覆盖。
