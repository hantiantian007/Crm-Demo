客户注册资料 - 需求说明书 (PRD)

所属模块：其他页面 | 更新日期：2026-09-20 | 当前版本：V1.0.0

一、页面用途与范围

  • 用于客户开户注册过程中的资料填写与身份信息提交，形成可追溯的资料记录。
  • 本 PRD 聚焦于页面字段定义、交互流程、提交校验与验收标准。

二、本次页面调整对照表

调整项 修改前 修改后 说明
地区字段 地区 地区（7 个固定选项） 作为居住地址的地区选择。
地址补充字段 无 省/州、城市、详细居住地址（必填） 用于完整填写居住地址信息。

三、注册资料字段定义

1. 字段清单

字段 类型 必填 规则与说明
地区 下拉 是 固定选项：越南、中国、中国香港、韩国、日本、泰国、新加坡。
手机号 区号下拉 + 输入框 是 区号与手机号均必填。
真实姓名 输入框 是 用于客户身份信息记录与核验。
出生日期 日期 是 选择客户出生日期。
证件类型 下拉 是 选项示例：护照、身份证 / ID。
证件号 输入框 是 记录证件号码。
证件照片（正面） 上传 是 证件正面照片。
证件照片（反面） 上传 是 证件反面照片。
省/州 下拉 是 必填下拉；选项根据“地区”联动加载；未选择地区时不可选；更换地区后清空省/州与城市。
城市 下拉 是 必填下拉；选项根据“省/州”联动加载；未选择省/州时不可选；更换省/州后清空城市。
详细居住地址 输入框 是 必填；客户填写街道、门牌、楼层等详细信息。

2. 地址字段口径说明

字段 含义 选项来源/规则 必填 保存内容与示例
地区 居住地址所属地区 必填；固定选项：越南、中国、中国香港、韩国、日本、泰国、新加坡。 是 保存：选项代码 + 中文/本地化名称 + 页面显示名称。示例：code=CN_HK，name_zh=中国香港，display=中国香港。
省/州 常住地址的省/州/行政区 必填；下拉；选项根据“地区”联动加载；未选择地区时不可选；更换地区后清空省/州与城市。 是 保存：选项代码 + 中文/本地化名称 + 页面显示名称。示例：地区=中国，code=GD，name_zh=广东省，display=广东省。
城市 常住地址的城市 必填；下拉；选项根据“省/州”联动加载；未选择省/州时不可选；更换省/州后清空城市。 是 保存：选项代码 + 中文/本地化名称 + 页面显示名称。示例：省/州=广东省，code=SZ，name_zh=深圳，display=深圳。
详细居住地址 街道、门牌、楼层等详细信息 必填；客户输入文本内容。 是 保存：页面填写内容。示例：XX路88号X座。
重要说明
  • 居住地址字段顺序：地区 → 省/州 → 城市 → 详细居住地址。
  • 客户填写的地址信息不等于实际使用地区；注册 IP、后续登录地区不属于本表单字段。

四、提交校验与错误提示

  • 提交按钮位于表单底部，提交前对必填字段进行校验。
  • 必填项：地区、省/州、城市、详细居住地址、手机号（区号+号码）、真实姓名、出生日期、证件类型、证件号、证件照片（正/反）。
  • 错误提示需明确指向缺失项，例如：请先选择地区 / 请先选择省/州 / 请先选择城市 / 请填写详细居住地址。

五、验收标准

  • 可通过菜单进入页面，并正常展示用户资料/账号安全 Tab。
  • 页面为窄版单列布局，字段纵向填写；证件正/反面上传入口并排。
  • 地区为必填下拉，固定选项为：越南、中国、中国香港、韩国、日本、泰国、新加坡。
  • 省/州与城市为必填下拉，且与地区/省/州存在三级联动：更换地区清空省/州与城市；更换省/州清空城市。
  • 详细居住地址为必填输入框。
  • 提交校验覆盖全部必填项，错误提示明确指向具体字段。
