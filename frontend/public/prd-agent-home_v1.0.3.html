1. 核心经营数据

1.1 模块展示内容
  • 指标卡：客户总数、活跃客户数、本月新增客户、客户净入金、客户交易量、本月返佣。
  • 说明文案：客户总数为当前快照；活跃客户统计最近30天；新增客户、净入金、交易量及返佣统计本月1日至当前时间。
1.2 统一统计口径
维度 说明
统计对象 客户（Client）。
统计范围 当前代理本人及伞下客户（包含当前代理直属客户 + 下级代理名下客户）。
数据来源 CRM 客户、资金流水（入/出金）、MT4/MT5 成交记录、返佣结算记录、代理关系树。
去重方式 按客户ID去重；一个客户多个 MT 账号仍计为 1 个客户。
排除的数据 测试、内部、禁用/注销客户不计入；失败、取消、冲正数据不计入；模拟交易不计入。
状态/异常判断 若客户归属关系发生调整，按统计时刻的有效归属关系参与统计；无有效归属的客户不计入。
点击明细范围 当前页面 KPI 卡片不提供点击明细（仅展示汇总值）。
1.3 指标计算公式
指标 统计时间 计算公式 / 规则
客户总数 当前快照 客户总数 = 当前统计范围内的去重客户数。
活跃客户数 最近30天 活跃客户数 = 最近30天存在有效真实入金或有效交易的去重客户数。
本月新增客户 本月1日至当前时间 本月新增客户 = 本月1日至当前时间完成注册的去重客户数。
客户净入金 本月1日至当前时间 客户净入金 = 成功真实入金 − 成功真实出金（按统计时间内发生时间汇总）。
客户交易量 本月1日至当前时间 客户交易量 = 统计周期内有效已平仓交易的标准手数（Lot）汇总。
本月返佣 本月1日至当前时间 本月返佣 = 本月已结算返佣 − 返佣冲正 − 返佣多发扣回（按结算入账时间汇总）。

2. 活动概览

2.1 模块展示内容
  • 活动卡：活动名称、活动时间范围、剩余天数、参与状态（已参与/未参加活动）。
  • 未参与：展示“立即参与”入口，弹窗选择用户类型（新用户/老用户）并确认参与。
  • 已参与：展示参与 MT 账号与参与时间；展示活动净入金与活动交易手数进度条。
2.2 统计规则
统计对象 客户维度判断达标；进度统计以参与确认的 MT 账号为统计口径。
统计范围 当前代理范围内客户；仅统计确认参与该活动的客户/账号。
统计时间 从“参与成功时间”起算至当前时间；活动结束后模块不展示。
数据来源 活动配置、活动参与记录、入/出金流水、成交记录。
计算公式
活动净入金 = 参与成功时间后成功真实入金 − 成功真实出金。
活动交易手数 = 参与成功时间后有效已平仓交易的标准手数（Lot）汇总。
达标条件：活动净入金 ≥ 1,000 USD 且 活动交易手数 ≥ 10 Lot。
去重方式 达标判断按客户ID去重；同一客户多个参与账号的达标以客户维度为准。
排除的数据 失败、取消、冲正的入/出金与成交不计入；模拟交易不计入。
状态/异常判断 老用户参与需选择 MT 账号；未选择则不可确认参与。
点击明细范围 当前仅支持参与操作与进度展示，不提供按客户维度的参与明细列表。

3. MT账户概览

3.1 模块展示内容
  • 账户范围切换：本人 / 伞下 / 全部。
  • 当前实时数据（快照）：当前MT余额、当前持仓量、当前浮动盈亏；展示数据最后同步时间。
  • 期间数据：按所选时间（今日/本周/本月/上月/自定义）展示入金、出金、交易量、平仓盈亏；指标名随时间条件动态变化（如“本周入金”）。
3.2 统计规则
统计对象 MT 账户（Account）汇总 + 客户维度关联归属。
统计范围
本人：当前代理自己名下 MT 账户。
伞下：当前代理直属客户 + 下级代理名下客户对应的 MT 账户。
全部：本人 + 伞下。
统计时间
当前快照：当前MT余额、当前持仓量、当前浮动盈亏，不受时间筛选影响。
期间统计：入金、出金、交易量、已平仓盈亏按所选时间统计。
数据来源 MT4/MT5 账户快照、持仓与浮动盈亏；CRM 入/出金流水；MT4/MT5 成交记录。
计算公式
当前MT余额 / 当前持仓量 / 当前浮动盈亏：取统计范围内 MT 账户最新快照汇总。
期间入金：统计周期内成功真实入金金额汇总。
期间出金：统计周期内成功真实出金金额汇总。
期间交易量：统计周期内有效已平仓交易的标准手数（Lot）汇总。
期间平仓盈亏：统计周期内已平仓订单的盈亏汇总。
去重方式 快照指标按 MT 账户汇总；期间流水按订单/流水ID累计，不按客户去重。
排除的数据 失败、取消、冲正的入/出金不计入；模拟交易不计入；无效成交不计入交易量与平仓盈亏。
状态/异常判断 自定义日期开始时间晚于结束时间、或日期为空时提示错误；期间数据不参与统计。
点击明细范围 当前模块不提供账户级明细跳转（仅展示汇总）。

4. 经营趋势

4.1 模块展示内容
  • 趋势指标切换：净入金 / 交易量 / 新增客户 / 返佣。
  • 展示口径：近30天趋势（按天聚合）。
4.2 统计规则
统计对象 客户（新增客户）与资金/交易/返佣事件（净入金、交易量、返佣）。
统计范围 当前代理本人及伞下客户。
统计时间 固定近30天（按自然日聚合），不受其他模块时间筛选影响。
数据来源 客户注册记录、入/出金流水、成交记录、返佣结算记录。
计算公式
净入金（日）= 当日成功真实入金 − 当日成功真实出金。
交易量（日）= 当日有效已平仓交易标准手数（Lot）汇总。
新增客户（日）= 当日完成注册的去重客户数。
返佣（日）= 当日已结算返佣 − 当日返佣冲正 − 当日返佣多发扣回（按结算入账时间）。
去重方式 新增客户按客户ID去重；其他为事件累计。
排除的数据 测试、内部、禁用/注销客户不计入；失败、取消、冲正事件不计入；模拟交易不计入。
状态/异常判断 当日无数据则为 0；不展示“暂无数据”提示，仅体现趋势线变化。
点击明细范围 点击趋势指标仅切换展示，不提供按日明细列表。

5. 客户运营提醒

5.1 模块展示内容
  • 提醒卡片：新注册未入金、已入金未交易、7天未交易、30天未活跃、大额出金客户。
  • 点击提醒卡进入明细弹窗，支持按“客户名称/邮箱、MT账号”筛选，支持分页。
5.2 统一统计规则
统计对象 客户（Client）。
统计范围 当前代理本人及伞下客户。
去重方式 按客户ID去重；不按 MT 账号计数。
排除的数据 测试、内部、禁用/注销客户不统计；失败、取消、冲正的入/出金不统计；模拟交易不统计。
数据来源 CRM 客户、资金流水、成交记录、CRM 登录日志、MT 登录日志、代理关系树。
5.3 五项提醒口径
A. 新注册未入金
统计时间最近7天内注册（按注册时间）。
进入条件注册时间在最近7天内，且累计成功真实入金金额=0。
移出条件产生第一笔成功真实入金后移出；若后续仍无交易，可进入“已入金未交易”。
计算公式新注册未入金客户数 = 最近7天注册 且 累计成功真实入金金额=0 的去重客户数。
去重维度客户ID。
异常判断注册不足24小时的客户也计入。
明细字段范围客户名称、客户邮箱、注册时间、注册地区、KYC状态、MT开户状态、累计真实入金、归属代理、最近联系时间。
B. 已入金未交易
统计时间最近30天（按首次成功真实入金时间）。
进入条件最近30天完成首次成功真实入金，且累计成功真实入金>0，且所有真实 MT 账户有效交易笔数=0。
移出条件产生第一笔有效交易后移出。
计算公式已入金未交易客户数 = 最近30天完成首次成功真实入金 且 有效交易笔数=0 的去重客户数。
去重维度客户ID。
排除的数据只有赠金/信用金的客户不计入；仅模拟账户交易不计入。
明细字段范围客户名称、客户邮箱、MT账号、首次入金时间、首次入金金额、有效交易笔数、最近登录时间、归属代理。
C. 7天未交易
统计时间按最后一次有效交易时间判断（距当前7至29天）。
进入条件历史存在有效真实交易，且最后一次有效交易时间距当前≥7天且<30天。
移出条件产生新的有效交易后移出；若距当前≥30天且满足沉默条件则进入“30天未活跃”。
计算公式7天未交易客户数 = 最后有效交易时间在7天前至29天前 的去重客户数。
去重维度客户ID。
排除的数据从未交易的客户不计入；已入金未交易客户不计入。
明细字段范围客户名称、客户邮箱、MT账号、最后交易时间、未交易天数、历史交易量、当前余额、最近登录时间、归属代理。
D. 30天未活跃
统计时间连续30天（按CRM/MT登录、入金、交易行为综合判断）。
进入条件注册已超过30天，且历史存在真实入金或真实交易；连续30天没有CRM/MT登录、成功真实入金、有效交易。
移出条件出现任一行为：CRM/MT登录、成功真实入金、有效交易。
计算公式30天未活跃客户数 = 连续30天没有登录、真实入金和有效交易行为 的去重客户数。
去重维度客户ID。
排除的数据注册不足30天的新客户不计入；从未入金且从未交易的客户不计入。
明细字段范围客户名称、客户邮箱、MT账号、最后登录时间、最后入金时间、最后交易时间、沉默天数、当前余额、历史净入金、归属代理。
E. 大额出金客户
统计时间本月1日至当前时间（按出金申请时间）。
进入条件统计周期内触发任意规则：单笔出金≥10,000 USD / 24小时累计出金≥20,000 USD / 出金占比≥80%。
移出条件出金申请被拒绝/取消/冲正后移出；或超出统计周期后不再计入。
计算公式大额出金客户数 = 统计周期内触发任意一条大额出金规则 的去重客户数。
去重维度客户ID（同一客户多笔触发仍计 1）。
状态/异常判断统计状态包含：待审核/审核中/已通过/已完成；不统计：已拒绝/已取消/已冲正。
明细字段范围客户名称、客户邮箱、MT账号、申请时间、单笔出金金额、24小时累计出金、当前资金、出金占比、审核状态、触发规则、归属代理。
5.4 点击后查看的明细范围
  • 点击提醒卡打开明细弹窗，弹窗内查询条件仅影响当前弹窗展示（不影响首页其他模块）。
  • 点击“查看客户”进入客户详情页；当客户ID为空时提示“客户详情为演示数据”。

6. 返佣概览

6.1 模块展示内容
  • 返佣卡：今日返佣、本周返佣、本月返佣、上月返佣。
  • 下级代理列表：展示下级代理的客户数、本月净入金、本月交易量、本月返佣。
6.2 返佣统计规则
统计对象返佣结算记录（Commission）。
统计范围当前代理本人及伞下产生的返佣；按归属代理树汇总。
统计时间按结算入账时间统计：今日/本周/本月/上月。
数据来源返佣结算与入账记录、返佣冲正记录、返佣多发扣回记录。
计算公式周期返佣 = 周期内已结算返佣 − 返佣冲正 − 返佣多发扣回。
去重方式按返佣结算单ID累计，不按客户去重。
排除的数据未结算/未入账记录不计入；冲正数据按冲正记录处理。
状态/异常判断若同一笔返佣发生冲正/扣回，则以冲正/扣回记录作为负向抵扣。
点击明细范围当前页面返佣卡不提供点击明细。
6.3 下级代理列表统计规则
统计对象下级代理（Sub Agent）。
统计范围当前代理的下级代理列表（仅展示下一级）。
统计时间本月1日至当前时间。
数据来源代理关系树、客户归属关系、资金流水、成交记录、返佣结算记录。
计算公式各字段按“该下级代理伞下客户”的本月净入金/交易量/返佣汇总口径统计；客户数按客户ID去重。
去重方式客户数按客户ID去重；净入金/交易量/返佣为事件累计。
排除的数据测试、内部、禁用/注销客户不计入；失败、取消、冲正数据不计入；模拟交易不计入。
状态/异常判断若下级代理被禁用，则默认不展示或展示为 0（由权限与配置决定）。
点击明细范围当前表格不提供点击跳转（仅展示汇总列表）。

7. 通知公告

7.1 模块展示内容
  • 展示公告列表：标题 + 日期；支持“最新”标识；提供“查看更多”入口。
7.2 统计规则
模块展示内容展示与代理相关的平台公告摘要（标题、发布日期）。
统计对象公告（Notice）。
统计范围平台公告范围；可按用户角色/地区/语言等规则过滤（由公告系统决定）。
统计时间按公告发布时间倒序展示；当前模块不支持置顶规则；默认展示最新若干条。
数据来源公告服务/内容管理系统（CMS）。
计算公式无金额/数量计算公式；仅列表展示。
去重方式按公告ID去重。
排除的数据已下线/已撤回公告不展示。
状态或异常判断“最新”标识由公告数据中的标记字段决定；当前模块不体现“已读状态”。
点击后查看的明细范围点击公告进入公告详情；点击“查看更多”进入公告列表页（/news/latest）。

8. 推广中心

8.1 模块展示内容
  • 邀请类型切换：直客邀请 / 代理邀请。
  • 展示邀请码与分享链接；支持复制邀请码、复制链接；支持查看二维码。
8.2 统计规则
统计对象邀请码与链接（推广资源）。
统计范围归属于当前登录代理的推广资源；切换仅影响展示的资源类型，不影响其他模块数据。
统计时间非时间统计模块；展示为当前有效邀请码与链接。
数据来源代理账号资料、推广资源配置（邀请码/链接生成规则）。
计算公式无金额/数量计算公式；仅展示与复制。
去重方式邀请码按类型（直客/代理）唯一；同一类型仅展示 1 组。
排除的数据失效/冻结的推广资源不展示（由资源状态决定）。
状态或异常判断复制失败时使用降级方案复制到剪贴板；二维码为展示型弹窗。
点击后查看的明细范围复制按钮仅执行复制；“查看二维码”打开二维码弹窗；不提供邀请明细列表跳转。
