【新需求 PRD】管理员入金

查看原型
本文档描述 管理员手动入金 场景新增的 入金类型 字段与提示规则。Demo 仅做演示交互。
1. 需求说明
目标 管理员手动入金时新增 入金类型，用于区分入金业务性质，并统一展示“是否计入真实入金”的提示。
入口 【出入金】>【待审核入金】页面，列表区左上角按钮 管理员入金。
2. 操作流程
1）管理员进入【待审核入金】页面。
2）点击列表区左上角【管理员入金】打开弹窗。
3）在弹窗中选择 入金类型，并填写现有字段（入金金额、MT账号、确认账号、MT Comment、备注）。
4）点击【确认】提交（Demo 中仅做页面演示与轻量必填校验）。
3. 字段说明
字段 类型 必填 说明
入金类型 下拉选择 是 用于区分管理员手动入金的业务性质。
4. 入金类型选项
选项真实入金补录 / 差额补入 / 活动奖励 / 账户补偿 / 账务调整 / 演示数据
5. 业务规则
入金类型是否计入真实入金
真实入金补录计入真实入金
差额补入计入真实入金
活动奖励不计入真实入金
账户补偿不计入真实入金，单独统计
账务调整不计入真实入金
演示数据不计入真实入金
6. 交互说明
入金类型下拉框下方展示提示：是否计入真实入金：xxx，并随当前选择实时联动更新。
7. Demo说明
1）Demo 仅做页面演示与交互展示，不实现真实持久化。
2）不实现复杂权限与接口安全、幂等、风控校验等逻辑，真实规则仅在本文档描述。
