目录

1. 需求背景

  • 销售差异化阶梯返佣上线后，需要在报表中展示奖励计算依据，以便财务与业务核对每笔奖励的命中规则与计算快照。

2. 本次新增筛选

筛选项 说明
规则来源 用于筛选奖励命中的规则类型。
规则对象 当规则来源为“代理规则”或“MT分组规则”时显示；默认规则不显示。

3. 本次主表新增或调整字段

  • 销售邮箱（主表展示，超长省略，悬浮显示完整内容）。
  • 奖励计算方式（主表展示）。
  • 计算手数（标准手）（主表字段名称统一为“计算手数（标准手）”。）
  • 返佣标准（主表展示，例如 2.50 USD/标准手）。
  • 操作/详情（主表新增“详情”入口，打开右侧 Drawer）。
  • 规则来源不在主表展示，仅在详情 Drawer 中展示。

6. 新增字段口径

字段名称 展示位置 数据来源 计算或取值规则 取值时点 示例
销售邮箱 主表 / 详情 / 导出 销售账号基础信息 通过奖励记录中的销售 ID 关联获取；历史记录使用奖励生成时保存的邮箱快照，不跟随后续销售资料修改而变化。 奖励记录生成时 sales-a@example.com
奖励计算方式 主表 / 详情 / 导出 销售交易返佣配置 取奖励生成时生效的销售交易返佣配置，取值：统一计算 / 规则计算 / 团队净入金阶梯计算；历史记录保存当时计算方式快照。 奖励记录生成时 团队净入金阶梯计算
原始交易手数 详情 / 导出 MT4/MT5 平仓交易记录 展示交易订单原始手数及账户单位。 平仓成交后 1.00 美分手
计算手数（标准手） 主表 / 详情 / 导出 奖励计算结果快照
计算标准手数 = 原始交易手数 × 对应账户及交易品种的标准手换算系数。
标准账户按标准手口径处理；美分账户按 MT 系统对应品种规格换算。
报表展示以奖励生成时保存的标准手数快照为准。
 奖励记录生成时 0.11 Lot
规则来源 仅详情 Drawer / 导出 最终命中的返佣配置 取值：默认规则 / 代理规则 / MT分组规则；优先级：MT分组规则 > 最近一级已配置代理规则 > 默认规则。 奖励记录生成时 MT分组规则
规则对象 详情 / 导出 规则命中结果快照 MT分组规则：记录命中的 MT 分组名称及标识；代理规则：记录最近一级命中代理的名称、账号及 ID；默认规则：显示“销售默认配置”。 奖励记录生成时 real\\VIP\\Cent
净入金统计范围 详情 / 导出 规则来源 默认规则：销售旗下全部代理及直客；代理规则：命中代理及其全部下级代理、直客；MT分组规则：销售旗下属于命中 MT 分组的账户。 奖励记录生成时 销售旗下属于命中MT分组的账户
计算时净入金 详情 / 导出 统计范围资金记录
真实净入金 = 累计真实入金 - 累计真实出金。
不计入：赠金、信用金、佣金账户资金、内部转账。
保存奖励生成时点快照，后续净入金变化不修改历史记录。
 奖励记录生成时 $126,000.00
命中净入金档位 详情 / 导出 命中规则阶梯配置 档位起始值 ≤ 计算时净入金 ≤ 档位结束值；最后一档“不设上限”仅判断净入金 ≥ 起始值；展示档位起始值和结束值。 奖励记录生成时 $100,000.00–不设上限
返佣标准 主表 / 详情 / 导出 命中档位返佣金额 取命中净入金档位对应的返佣金额，单位：USD/标准手；保存奖励生成时的返佣标准快照。 奖励记录生成时 2.50 USD/标准手
奖励金额 主表 / 详情 / 导出 奖励计算快照
团队净入金阶梯计算：奖励金额 = 计算标准手数 × 命中档位返佣标准。
统一计算：奖励金额 = 计算标准手数 × 统一返佣标准。
规则计算：奖励金额 = 计算标准手数 × 最终命中规则返佣标准。
计算过程保留完整精度；报表统一展示 4 位小数；金额舍入方式沿用现有奖励入账规则。
 奖励记录生成时 0.2750 USD
计算公式 详情 / 导出 奖励记录快照 展示参与计算的标准手数、返佣标准和最终金额。 奖励记录生成时 0.11标准手 × 2.50 USD/标准手 = 0.2750 USD
配置版本 详情 / 导出 返佣配置元数据 记录奖励计算时使用的配置 ID、版本号及生效时间，用于历史奖励追溯；后续配置变更不覆盖历史版本。 奖励记录生成时 V1.0
导出 导出文件 同报表详情 导出字段与报表详情使用相同的数据来源和计算快照；导出结果不得使用当前最新配置重新计算历史奖励。 导出生成时 CSV/Excel

7. 导出新增字段

  • 导出字段需同步包含本次新增的计算依据与快照字段（与详情 Drawer 中的计算依据字段一致）。

8. 验收标准

  • 主表新增/调整字段正确展示（销售邮箱、奖励计算方式、计算手数（标准手）、返佣标准、操作/详情）。
  • 规则来源只在详情 Drawer 中展示，不在主表展示。
  • Drawer 可查看完整计算依据（包含规则来源/对象、净入金、命中档位、公式与配置版本）。
  • 导出包含本次新增字段与计算依据快照字段。
  • 交易品种继续沿用原字段，不新增产品名称。
