先锋一号 50,000 USD 体验金活动详情与盈利释放

本活动复用现有“活动参加 + 活动审核”流程，不新增独立的“盈利释放申请审核”。

参与与审核流程

  • 首页立即参加
  • 客户填写模拟账户账号
  • 上传模拟账户截图
  • 提交参加活动申请
  • 后台活动审核（通过 / 拒绝）
  • 审核通过后正式开始活动
  • 从审核通过时间开始累计净入金
  • 达到档位后逐档触发盈利释放
  • Lot 累计计算，不清零

客户参加弹窗（沿用现有参加方式）

不假设存在 Star API，不新增 Star 自动同步字段。

  • HATC 参与 MT 账号
  • 模拟账户账号
  • 模拟账户截图
  • 活动条款确认

后台审核列表（复用：活动管理 > 活动审核）

  • 增加/支持筛选：申请活动 = 先锋一号 50,000 USD 体验金活动
  • 列表结构沿用现有活动审核列表

审核弹窗（复用现有审核 Modal）

  • 展示：客户姓名、客户邮箱、上级信息、注册时间、报名时间、HATC 参与 MT 账号、模拟账户账号、客户上传截图
  • 审核字段：审核结果（通过/拒绝）、审核备注、拒绝原因（拒绝时必填）
  • 本次审核仅为“参加活动资格审核”，不在此填写盈利释放金额。

审核通过后的规则

  • 审核通过时记录：审核通过时间、审核人
  • 以“审核通过时间”作为活动净入金统计起点；通过前所有入金不计入活动
  • 每达到一个新档位触发一次释放
  • 本次释放金额 = 当前档位累计应释放金额 - 历史已释放金额
  • Lot 累计目标不清零

档位（净入金 → 释放比例）

  • $5,000 → 10%
  • $10,000 → 20%
  • $15,000 → 30%
  • $20,000 → 40%
  • $25,000 → 50%
  • $30,000 → 60%
  • $35,000 → 70%
  • $40,000 → 80%
  • $45,000 → 90%
  • $50,000 → 100%

Lot 累计目标

50 / 100 / 150 / 200 / 250 / 300 / 350 / 400 / 450 / 500 Lot（不清零）
