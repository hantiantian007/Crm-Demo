后台操作审计记录

用于记录后台人员查看客户详情、导出报表数据的关键操作行为，支持筛选、查看详情与导出审计数据（导出行为本身也会被记录）。

记录范围

  • 查看客户详情：每次打开客户详情页成功后生成一条记录（不合并，刷新也按实际记录）。
  • 导出报表数据：每次导出成功/失败都生成一条记录，失败需记录原因。
  • 不记录普通列表浏览、筛选、分页等低价值操作。

审计字段

字段 说明
操作记录 ID唯一标识
操作类型查看客户详情 / 导出报表
操作人员姓名、账号、角色
操作时间记录生成时间
客户或报表名称客户名称或报表名称
客户 ID / 报表类型客户 user_id 或报表类型标识
导出条件时间范围、筛选条件、数据范围（以结构化对象保存）
导出条数导出的数据条数
操作结果成功 / 失败
失败原因失败时必填
IP 地址演示环境使用固定值展示
设备或浏览器信息UA 信息
关联页面触发操作的页面路径

页面功能

  • 入口：系统管理 / 操作审计。
  • 筛选：操作类型、操作人员、客户/报表、时间范围、操作结果。
  • 列表：表格展示审计记录，支持查看详情。
  • 详情：展示完整导出范围与环境信息。
  • 导出审计：可导出当前筛选结果为 CSV；导出行为也会生成一条导出审计记录。

权限与数据安全（演示）

  • 审计记录只允许查看，不允许普通管理员修改或删除。
  • 如需清理，应由专门权限执行，并同样需要留下审计记录（后续扩展）。
