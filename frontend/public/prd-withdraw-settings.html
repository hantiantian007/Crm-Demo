0. 本次新增能力概览

0.1 提现设置主页面
  • 顶部：状态筛选（启用）/ 添加信息 / 配置记录 / 当前命中通道提示。
  • 列表字段：编号、简称、支付编号、名称、商户号、AppId、币种、提示语、汇率、汇率来源、状态、操作（修改、启用/禁用）。
0.2 配置记录入口
  • 入口：系统管理 → 提现设置页顶部按钮「配置记录」。
  • 跳转：/fund/withdraw-config-records（提现配置记录）。
  • 结构：页面内 Tab：配置日志 / 每日通道汇率。
0.3 配置日志（审计）
  • 字段：操作时间、操作人、提现通道、操作类型、变更内容、备注。
  • 操作类型：新增提现方式 / 修改配置 / 启用 / 禁用。
  • 变更展示：同一次修改只生成 1 条日志，详情中展示多个字段的「修改前 → 修改后」。
  • 筛选：提现通道 / 操作类型 / 时间范围；默认按操作时间倒序。
  • 只读：不可编辑、不可删除。
0.4 业务汇率记录
  • 核心规则：只有真实发生“出金”业务，并且该笔业务真正使用了汇率时，才生成业务汇率记录。
  • 不记录：仅调用接口查询汇率、页面打开时展示汇率、后台人工查看汇率、查询后业务未继续完成。
  • 字段：业务时间 / 通道 / 简称 / 汇率来源 / 接口返回汇率 / 实际使用汇率 / 获取时间。
  • 筛选：日期范围 / 通道 / 汇率来源；默认按业务时间倒序。
  • 接口查询：只保留“接口获取成功”的业务汇率记录；业务汇率记录页中接口数据默认都是成功记录，不展示获取失败/接口异常/备用汇率记录。
  • 页面配置：接口返回汇率显示“-”；实际使用汇率显示页面配置实际采用值；获取时间显示生效/取值时间。
  • 只读：历史记录不可编辑、不可删除。
0.5 Demo 与正式系统差异
  • Demo：使用演示数据；不接真实提现接口/汇率接口；不做真实持久化；业务汇率记录仅展示接口成功与页面配置两种来源。
  • 正式：需要真实审计字段（操作人、时间、前后值、类型等）；每日通道汇率需按通道/币种/获取状态/失败原因/备用来源等留存，支持财务对账与争议核查。
