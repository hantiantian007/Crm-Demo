2. 核心业务规则

2.1 返佣数量计算

指标 / 规则计算口径
应返佣订单数原有规则判定符合返佣条件的平仓订单数。
CRM返佣订单数已产生 CRM 返佣记录的平仓订单数，沿用原 CRM 统计口径。
MT返佣订单数只有一笔平仓订单的全部应收佣代理均匹配到 MT5 入账才计 1 笔；金额是否一致独立判断。
差异公式CRM数量差异 = CRM返佣订单数 − 应返佣订单数。
MT数量差异 = MT返佣订单数 − CRM返佣订单数。
去重与计数顶部按去重后的平仓订单计数；一笔订单涉及多级代理仍计 1。返佣人数按 CRM 稳定代理标识去重，不按姓名或 MT5 流水笔数计数。
边界与来源应收代理清单、平仓订单及 CRM 返佣记录为核对基准；无应收佣代理的订单不计 MT订单数，不自动计异常。数量为 Integer（笔/人）；来源未完整取得显示“—”，不得冒充 0。

2.2 返佣金额计算

指标 / 规则计算口径
应返佣金额沿用现有规则的 CRM 理论应返佣金额。
CRM实际返佣金额本批次 CRM 已记录的实际发放佣金。
MT返佣金额与本批次订单及收款代理佣金记录实际匹配到的 MT5 入账金额。
差异公式CRM金额差异 = CRM实际返佣金额 − 应返佣金额。
MT金额差异 = MT返佣金额 − CRM实际返佣金额；代理级同样按 MT 实际入账 − 对应 CRM 返佣计算。
币种及精度Decimal；统一币种、单位与精度，USD/USC 原始数值不得混加。保留来源精度，不用显示后舍入字符串比较；转换、汇率时间点、舍入及容差未确认时不得自行设定。
汇总一致性代理 → 订单 → 完整批次逐级核对，列表与详情同批次一致；不随筛选、分页变化。同一流水重复读取不重复汇总；已确认的实际重复入账如实计入并标异常。
未知与真实 0未获取、未完整取得或无法确认的金额及依赖差异显示“—”，不用 CRM 金额补齐。真实 0 正常参与运算；完整查询且等待期后确认无入账，可记确认入账总额 0，但无流水且不计已匹配代理。
展示沿用统一金额精度（如 $42,920.90）；MT 与 CRM 金额相等绿色，不等红色，未知灰色“—”。数量/金额差异为 0 显示正常，非零红色并保留正负号。

2.3 MT5 入账匹配规则

环节必须执行的规则
识别与关联注释组成：CM + MT账号 + 平仓交易编号；结合交易 MT账号、真实平仓 Deal 编号、实际收款代理 MT5佣金账号、CRM对应返佣记录、实际入账金额及流水核对。保留现有客户/账户授权范围。
标识不可混用页面平仓单号不一定是 MT5 Deal 编号，不用 Order 编号或猜测值替代；交易账号与收款佣金账号分别校验。注释分隔符/长度边界未确认时不猜测拆分。
多级与重复不同代理相同注释可为合法入账。重复须结合同一收款佣金账号、同一应发记录/佣金义务及不同真实流水确认；重复抓取同一流水不算重复资金。合法拆分、特殊合并或重复性质不明时待核实。
跨日与到账等待按原佣金发放记录追踪跨日流水，归入原批次，不按自然日错判或重复归批；未完成入账/等待期内为待核实。只有超过确认的等待期且完整数据证实无对应入账，才判漏入账。等待期及查询窗口不自行假定。
逐代理核对逐代理比较金额并保存流水事实；只有全部应收佣代理关联完成才计 MT订单数。多笔流水保留逐笔及代理汇总，同一 CRM 基准金额不重复累计；不凭当天总额相等认定所有订单正常。
数据失败读取失败、超时或分页未完整取得标记受影响核对“对账失败”并保存原因；可保留已知代理事实，但不能以部分金额冒充完整汇总，不能把来源失败当空列表或 0。

2.4 MT5 对账异常规则

MT对账结果判定条件及边界
正常所需数据完整，全部应收佣代理入账关联完成，数量及金额均匹配且无已确认重复；不能用未知差异判正常。
少入账已匹配实际入账，确认 MT 金额小于对应 CRM 已发金额；差异为负，与完全无入账的漏入账区分。
多入账确认 MT 金额大于 CRM 已发金额且非已确认重复入账；差异为正。
漏入账超过已确认到账等待期，跨日/延迟因素已核实，完整数据仍确认应收佣代理无对应入账；不得由未同步或接口失败推断。
重复入账同一收款佣金账号、同一应发记录出现超出预期且已确认重复的实际资金入账；保留所有真实流水和金额。
待核实尚未同步/核对、入账未完成、关联有歧义、必要字段缺失或拆分/合并/重复性质无法确认；已知值可保留，未知值“—”。
对账失败MT5 数据读取或核对过程失败，无法得出结论；明确失败原因，不等同漏入账或 0 金额。

同一订单保留各代理的不同结果；混合异常汇总优先级待确认，不以“正常”掩盖异常。CRM 对账、MT5 对账、人工处理状态分别记录；标记“已处理”不代表已到账，不改变 CRM 原异常笔数/差额，不清零真实差异，不新增自动补发、冲正或其他资金操作。

4. 验收标准

测试条件预期结果
数量、金额及各代理匹配一致MT对账正常，MT数量/金额差异为 0；不能仅校验批次金额。
MT订单数少于 CRMMT数量差异为负；缺少任一应收佣代理的订单不计入 MT订单数，待核实或漏入账按确认条件区分。
已入账但 MT金额少于 CRM少入账，MT金额差异为负；完整入账关联仍可计 MT订单数。
MT金额大于 CRM，非确认重复多入账，MT金额差异为正。
超过确认等待期仍无入账完整数据并排除跨日/延迟后判漏入账；未到确认条件则待核实。
同一应发记录有确认重复资金重复入账，真实多笔金额如实汇总；重复抓取同一流水不多计。
一笔交易向多个代理返佣全部应收代理关联后订单仅计 1；MT人数按不同收款代理计，不按流水笔数计。
不同代理使用相同入账注释按实际收款佣金账号及对应记录区分，不仅凭注释判重复。
CRM发放与 MT入账跨日追踪原记录并归原批次，不直接判漏入账；入账未完成或关联不明为待核实。
读取失败 / 超时 / 分页不完整对账失败并记录原因；未知金额及差异“—”，不能以 0 或部分合计代替。
USD、USC 金额单位不同按已确认的同币种、单位和精度比较，不直接相加；口径未确认则待核实。
列表、详情、全量明细及代理流水核对同批次人数/金额逐级一致，筛选或分页不改变批次汇总；代理少入与多入相抵也不得整体判正常。
原 CRM 异常已人工处理CRM 结果及异常笔数/差额不被 MT覆盖；已处理不等于 MT到账，无资金修改操作。
无数据、真实 0、确认无入账缺失“—”；有效流水真实 0 参与金额比较且保留匹配事实；确认无入账为 0 总额但不计匹配代理，编号/时间仍“—”。
不涉及返佣或匹配不明无应收代理显示不适用“—”，不计 MT订单或额外异常；注释/Deal/账号不明确时待核实，不猜测匹配。
