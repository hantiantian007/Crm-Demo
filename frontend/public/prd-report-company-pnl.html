报表中心 - 公司盈亏报表 PRD

第一版为 Demo 页面：使用演示数据，不接真实接口；页面展示金额统一折算为 USD。
版本：v1 Demo

页面目标

  • 给运营/财务提供“公司维度”的整体盈亏概览与趋势，快速定位异常波动与贡献来源（客户/产品/短时交易）。
  • 面向风控/业务分析：提供 <=120 秒短时交易的客户与产品分析入口（放在页面后部，避免抢主视觉）。
  • 数据优先、轻量报表风格：避免大量大卡片，核心指标集中展示，表格支持排序。

页面结构

  1. 筛选区
  2. 公司盈亏总览
  3. 本月累计公司盈亏
  4. 公司盈亏趋势（月度 / 年度）
  5. 客户分析 Tabs（Top 20）
  6. 产品分析（统一表格）
  7. <=120 秒交易分析（客户维度 / 产品维度）
  8. 月度 / 年度汇总表

筛选区

筛选项：日期 / 日期范围、公司、币种、查询、重置。
公司演示数据：支持 HATCGL、HATC-HK、全部。
币种：筛选用于限定“原始流水币种”维度；页面最终展示统一折算为 USD。
时间：Demo 支持单日/区间输入（YYYY-MM-DD）。正式系统需明确对齐 MT5 Server Time 与统计口径。

顶部采用轻量 KPI，优先展示以下指标（金额为 USD，手数为 Lot）：

公司净盈亏口径：页面只展示最终统计结果；正式系统必须由统一后端/财务口径提供，前端禁止硬编码一套新的计算逻辑。
现有报表涉及因素包括：平仓盈亏、平仓利息、返佣、手续费、浮动盈亏、调整金额、分成业务占比等。

本月累计公司盈亏

单独区域展示本月累计字段：
  • 前期累计总盈亏

维度：支持月度、年度；公司支持 HATCGL 与 HATC-HK。
趋势图第一版：重点展示公司净盈亏、净入金、平仓盈亏、返佣；避免一次做过多图。
表格字段（参考现有年度报表）：月份/年度、公司、净值、净入金、信用金额、平仓笔数、平仓手数、手续费、平仓利息、平仓盈亏、返佣、浮动盈亏、公司净盈亏、代理佣金账户。

产品分析

将 Excel 横向多组产品列表整理为一张统一表格。
字段：交易产品、平仓笔数、交易量、交易量占比、平仓盈亏 + 返佣。
排序：支持按交易量/占比/盈亏排序。
演示产品示例：XAUUSD、XAUUSD.cent、XAGUSD、XTIUSD、EURUSD、GBPUSD 等。

<=120 秒交易分析

口径：单笔交易从开仓到平仓的持仓时长 <= 120 秒，计入短时交易统计。
客户维度字段：MT5 Login、客户名称、<=120 秒交易占率、<=120 秒平仓笔数、总平仓笔数、<=120 秒交易盈亏、期间总盈亏。
产品维度字段：交易产品、<=120 秒笔数、<=120 秒占率、<=120 秒盈亏 + 返佣。

公司净盈亏业务说明（关键规则）

公司净盈亏不是“客户亏损 = 公司盈利”的简单对立关系。
现有报表实际涉及多因素：平仓盈亏、平仓利息、返佣、手续费、浮动盈亏、调整金额、分成业务占比等。
正式系统的公司净盈亏公式必须由统一后端/财务口径提供；前端仅展示后端输出的最终统计结果。

返佣规则与异常提示

返佣规则：返佣按最高条件计算。
异常提示：当代理净入金金额与返佣金额差距明显异常时，提示运营/IT 检查返佣系统。
Demo 阶段仅展示状态 待核查，不实现真实异常判定算法。
