活动管理 研发中

活动审核（新增：先锋一号 50,000 USD 体验金活动）

目标：在现有“活动管理 > 活动审核”页面中，新增支持“先锋一号 50,000 USD 体验金活动”的报名审核能力。审核页负责参加资格审核，并在审核通过时录入盈利金额（USD）作为后续奖励/释放计算基数。

业务流程

  • 客户首页点击【立即参加】
  • 选择 HATC MT账号，填写模拟账户账号，上传模拟账户截图，提交申请
  • 后台进入【活动管理 > 活动审核】查看申请并处理【通过/拒绝】
  • 审核通过后记录审核人、审核通过时间；从审核通过时间开始累计本活动净入金（通过前入金不计入）
  • 审核通过时管理员填写：盈利金额（USD）
  • 前端统一按 USD 填写与展示；美分账户换算由后台处理，前端不展示美分原始值

筛选区（复用现有结构）

  • 客户姓名
  • 客户邮箱
  • 申请活动（需包含：先锋一号 50,000 USD 体验金活动）
  • 审核状态（待审核 / 已通过 / 已拒绝）

审核列表（复用现有表格风格）

  • 客户姓名、客户邮箱、上级信息、注册时间、申请活动、申请时间、审核状态、拒绝原因、操作
  • 操作策略：待审核显示【查看】【审核】；已通过/已拒绝仅显示【查看】

查看详情

复用现有“查看详情”弹窗交互，展示报名与审核信息。

  • 客户姓名、客户邮箱、上级信息、注册时间
  • 报名时间、HATC MT账号、模拟账户账号、模拟账户截图（可点击预览大图）
  • 审核状态、审核人、审核时间、拒绝原因（如有）

审核弹窗（居中 Modal，复用样式）

  • 标题：审核
  • 顶部两列只读信息：客户姓名/邮箱、上级信息、报名时间、注册时间、申请活动、HATC MT账号、模拟账户账号、模拟账户截图（可预览）
  • 底部审核表单新增：盈利金额（USD）
  • 盈利金额（USD）规则：
  • 1) 当审核结果=通过时必填；当审核结果=拒绝时可不填
  • 2) 允许输入 0 或正数；盈利金额 ≤ 0 时不产生奖励
  • 3) 统一按 USD 填写与展示；美分账户换算由后台处理
  • 审核结果（必填：通过/拒绝），审核备注（可选）
  • 当选择【拒绝】时额外展示：拒绝原因（必填），补充说明（当拒绝原因=其他时必填）

拒绝原因示例

模拟账户信息不符 / 截图无法确认 / 资料不完整 / HATC MT账户不符合要求 / 重复申请 / 其他

状态定义

  • 审核状态：待审核、已通过、已拒绝
  • 盈利金额（USD）作为奖励/释放计算基数

Demo 约束

  • 使用演示数据，不接 Star API，不接真实 MT5
  • 不做真实文件存储；模拟账户截图仅做上传/预览演示
  • 审核通过/拒绝后仅前端更新状态，不做真实持久化
