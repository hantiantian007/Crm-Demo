销售差异化阶梯返佣配置 - PRD

范围声明
  • 本 PRD 用于描述“销售差异化阶梯返佣配置”的规则口径与页面交互。
  • 当前阶段仅用于前端演示（演示数据），不连接真实接口，不实现真实净入金统计与返佣计算。

1. 需求背景

  • 不同销售、代理层级和 MT 分组的客户质量与净入金门槛不同，单一固定返佣规则无法满足差异化销售政策。
  • 需要根据销售团队真实净入金档位，确定每标准手返佣金额，并支持按代理、按 MT 分组配置差异化阶梯。

2. 适用页面

页面 路由 说明
销售列表 /commission/sales-list 展示销售配置列表，并提供 PRD 入口。
新增销售 /commission/sales-list/create 配置销售的交易返佣计算方式；当选择“团队净入金阶梯计算”时，配置默认阶梯与差异化规则。
  • 后续“编辑销售”页面可复用同一规则与交互规范。

1. 默认阶梯返佣（团队净入金阶梯）

3.1 规则定义

  • 默认阶梯规则覆盖未命中任何代理特殊规则与 MT 分组特殊规则的交易账户。
  • 阶梯以“累计真实净入金”作为档位判断依据，输出“每标准手返佣金额”。

3.2 初始演示规则

净入金起始值（USD） 净入金结束值（USD） 返佣金额 单位
0.00 99,999.99 1.50 USD/标准手
100,000.00 不设上限 2.00 USD/标准手

3.3 可配置能力

  • 支持：编辑 / 新增档位 / 删除档位 / 保存 / 取消。
  • 第一档起始值固定为 0.00。
  • 第二档及后续档位起始值自动计算为：上一档结束值 + 0.01（按“美分整数”计算，避免浮点误差）。
  • 起始值只读，不允许手动修改。
  • 最后一档结束值固定为“不设上限”，且必须是最后一行，只能存在一行。
  • 至少保留一档，不能全部删除。
  • 连续新增控制：若当前新增的非最后档位未填写结束值，则禁止继续新增，并提示用户先填写结束值。

2. 动态档位校验

4.1 保存校验规则

  • 每个非最后档位必须填写结束值。
  • 结束值不得小于当前档位起始值。
  • 返佣金额必填且不得小于 0。
  • 所有数字最多保留 2 位小数。
  • 档位必须连续，不能重叠或留空；最后一档必须为“不设上限”。
  • 错误提示需明确到具体档位，例如：第2档净入金结束值不能为空、第3档结束值必须大于等于起始值。

4.2 编辑联动校验

  • 修改任意前置档位结束值后，立即重新计算后续档位起始值。
  • 若重算后出现“后续结束值小于起始值”，对应输入框显示错误状态并禁止保存。

3. 差异化阶梯开关与入口

  • 差异化阶梯默认关闭；开启后显示“配置差异化阶梯”入口。
  • 进入差异化配置前必须先选择销售名称。
  • 未选择销售名称点击入口：提示 请先选择销售名称，并定位销售名称字段。

4. 差异化阶梯配置（弹窗）

6.1 弹窗结构

  • 弹窗标题：差异化阶梯配置。
  • 包含两个 Tab：按代理配置 / 按 MT 分组配置。
  • 弹窗展示当前销售名称；同一订单只命中一套规则，不叠加返佣。

6.2 按代理配置

  • 左侧：代理关系树（仅演示数据），支持展开/收起、搜索、已配置状态展示。
  • 右侧：选中代理的阶梯配置，默认可复制默认阶梯后进行调整。
  • 统计范围：该代理及其全部下级代理、直客的净入金合计（口径见第 6 节）。
  • 多级代理同时配置时，采用“距离客户最近一级”的已配置代理规则。
  • 独立阶梯的编辑能力与默认阶梯一致（新增/删除/保存/取消、动态校验）。

6.3 按 MT 分组配置

  • 左侧：MT 分组列表（仅演示数据），支持搜索、已配置状态展示。
  • 右侧：选中分组的阶梯配置，默认可复制默认阶梯后进行调整。
  • 统计范围：当前销售名下、属于该 MT 分组的交易账户净入金合计（口径见第 6 节）。
  • 独立阶梯的编辑能力与默认阶梯一致（新增/删除/保存/取消、动态校验）。

5. 规则优先级

  • MT 分组规则 > 最近一级已配置代理规则 > 默认阶梯规则。
  • 每笔交易只命中一条规则，不叠加多个返佣金额。
  • 已结算交易不因规则变化重新计算；规则变化只影响生效后的符合条件交易。
  • 代理关系或 MT 分组变化后，仅影响后续订单。

6. 净入金统计口径

  • 净入金 = 真实入金 - 真实出金。
  • 不计入：赠金、信用金、佣金账户资金、内部转账。
  • 净入金不按月重置；净入金下降后，后续交易按下降后的档位计算。
  • 交易量统一按标准手统计。

7. 销售切换

  • 若已存在差异化配置，更换销售名称需二次确认：
  • 更换销售后，当前差异化阶梯配置将被清空，是否继续？
  • 确认：切换销售并清空差异化配置；取消：保留原销售与配置。

8. 页面交互与状态

  • 编辑前保存数据快照。
  • 保存后更新当前页面演示状态。
  • 取消后恢复编辑前数据。
  • 配置弹窗关闭或取消时，不保留未保存修改。
  • 当前阶段仅使用演示数据，不接真实接口。

9. 验收标准

11.1 默认阶梯

  • 支持新增/删除档位，起始值自动衔接，最后一档始终为“不设上限”。
  • 保存时触发档位连续、非空、金额精度等校验，错误提示可定位到具体档位。
  • 取消可恢复编辑前快照。

11.2 差异化配置

  • 差异化开关开启后可进入弹窗；未选择销售时点击入口会提示并定位销售名称字段。
  • 按代理配置：可对代理配置独立阶梯，并支持新增/删除/保存/取消与动态校验。
  • 按 MT 分组配置：可对分组配置独立阶梯，并支持新增/删除/保存/取消与动态校验。
  • 保存时校验所有已启用的代理与 MT 分组规则；错误提示包含对象名称与档位。

11.3 优先级

  • 优先级遵循第 5 节；同一订单只命中一条规则，不叠加。

12. 边界与非本期范围

  • 不实现真实净入金统计。
  • 不实现真实交易返佣计算。
  • 不连接真实代理关系与 MT 分组接口。
  • 不处理历史订单重新结算。
  • 不修改净入金奖励配置、不修改基础分佣配置。
