报表中心 PRD（活动参与报表 - 星际起航免费开卡）

目标用户：市场、运营、代理管理
数据来源：Mock（本期 Demo 不接真实 API）
更新日期：2026-09-11
状态：草稿
说明：本期目标为 Demo，可用 Mock 数据体现“直属 / 团队”差异、代理汇总与客户明细下钻；复杂业务校验与真实计算仅写入本 PRD，不在 Demo 强实现。

1. 业务目标

  • 统计每个代理旗下客户参与活动情况，支持代理汇总与客户下钻明细。
  • 支持按活动、活动时间、代理、客户/MT、参与状态与统计范围筛选。
  • KPI 快速呈现：参与客户数/参与率、达标客户数/达标率、活动净入金、活动交易量；并可补充接近达标客户数、待发/已发奖励。

2. 页面结构

2.0 左侧代理关系树（入口）
  • 搜索：支持按代理/客户关键字搜索，并支持 MT 账号命中。
  • 展开：支持展开下级代理节点；展示直属客户节点。
  • 高亮：当前选中节点高亮。
  • 选中代理：右侧数据按“该代理范围”刷新；并继续结合统计范围（直属/团队）。
  • 选中客户：右侧直接筛选到该客户/MT 相关活动数据。
2.1 顶部筛选
  • 一行核心筛选：活动 / 时间 / 参与状态 / 统计范围 / 查询。
  • 更多筛选（展开）：代理账号/名称、客户/MT账号；重置放在更多筛选中。
2.2 KPI
  • 核心 KPI（卡片）：参与客户数、参与率、达标客户数、达标率、活动净入金、活动交易量。
  • 辅助指标（轻量文字）：接近达标、待发奖励、已发奖励。
2.3 代理汇总表
字段 说明
代理账号代理唯一标识（如 IB1001）。
代理名称代理展示名称。
客户数当前统计范围下的客户总数（直属/团队）。
参与客户数成功参与活动的去重客户数。
参与率参与客户数 / 客户数。
已达标满足全部达标条件的去重客户数（含待发放/已发放）。
达标率达标客户数 / 参与客户数。
活动净入金活动参与成功后有效入金 - 有效出金。
交易手数活动参与成功后累计有效交易 Lot。
查看明细打开右侧 Drawer，展示该代理下客户活动明细。
明细补充信息参与MT数、进行中、接近达标、待发奖励、已发奖励等从主表移入明细 Drawer 顶部信息区。
2.4 客户活动明细（右侧 Drawer）
  • 客户ID、客户姓名、MT账号
  • 活动名称、参与时间
  • 净入金及进度（进度条最高 100%，数值显示真实）
  • 交易手数及进度（同上）
  • 平仓盈亏（含 Swap / 利息，仅已平仓，不含浮动盈亏）
  • 返佣金额（参与成功时间后产生）
  • 状态：进行中 / 已达标 / 待发放 / 已发放
  • 奖励金额、奖励状态、奖励时间
  • “接近达标”：任一核心指标达到 80% 以上但尚未全部达标（可标签）
  • 仅展示参与客户：明细只展示“已成功参加当前所选活动”的客户；未参加不进入明细列表。
  • 关系树展示全部关系：左侧关系树仍展示该代理下全部代理/客户，用于关系定位与筛选。

3. 关键统计口径

3.1 基本口径
  • 参与客户数：成功参与活动的去重客户数。
  • 参与率：参与客户数 / 当前统计范围客户数。
  • 达标客户数：满足活动全部条件的去重客户数。
  • 达标率：达标客户数 / 参与客户数。
  • 活动净入金：活动参与成功后有效入金 - 有效出金。
  • 活动交易量：活动参与成功后累计有效交易 Lot。
  • 接近达标客户数：任一核心指标达到 80% 以上但尚未全部达标的去重客户数。
  • 同一客户可有多个 MT，因此参与客户数与参与MT账号数分开统计。
  • 关系树选中节点与统计范围：若关系树选中代理，则统计范围以该代理为根；直属=仅该代理直属客户，团队=该代理及其下级代理客户。
  • 关系树选中客户：右侧等价于自动填充“客户/MT账号”筛选条件，仅展示该客户相关记录。
3.2 统一时间口径（本需求修正点）
  • 统一规则：所有活动相关数据，均从“客户主动申请并成功参与活动的时间”开始计算。
  • 统计区间：开始时间 = 客户活动参与成功时间；结束时间 = 活动结束时间或当前时间，取较早者。
  • 统一应用：活动净入金、活动交易量、平仓盈亏（含 Swap/利息）、返佣金额、达标进度、奖励相关统计，全部使用上述同一统计区间。
  • 示例：活动时间 2026-09-01 ~ 2026-09-28，客户参与成功 2026-09-10 14:30，则 2026-09-10 14:30 之前的入金/出金/交易量/平仓盈亏/Swap/返佣全部不计入。
3.3 平仓盈亏口径
  • 只统计已平仓交易。
  • 包含 Swap / 利息。
  • 不包含浮动盈亏。
3.4 返佣口径
  • 只统计参与成功时间之后产生的返佣。
  • 按该活动参与客户及对应代理归属汇总。

4. 星际起航免费开卡口径（默认示例）

  • 净入金目标：$1,000
  • 交易目标：10 Lot
  • 两项都完成才达标
  • 统计起点为活动参与成功时间
  • 参与前产生的入金、出金、交易量不计入
  • 新用户默认使用赠金 MT 账号；老用户使用参与时选择的 MT 账号

5. 仅写入 PRD（Demo 暂不实现）

  • 同一 MT 账号同一活动只能参加一次
  • 正式代理树递归（团队口径）
  • 历史代理归属快照
  • 客户活动资格校验
  • 真实净入金/交易量计算（含剔除、时区、订单修正等）
  • 奖励真实发放与状态同步
  • 数据库存储与审计
