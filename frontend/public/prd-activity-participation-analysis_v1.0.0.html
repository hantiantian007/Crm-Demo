1. 需求说明

从活动维度分析代理及其伞下客户的参与度、达标率及业务贡献（净入金、交易手数、活跃客户等）。本页面不以奖励金额为核心，因为部分活动可能没有赠金、体验金或资金奖励。

2. 操作流程

  1. 进入【活动管理】>【活动参与分析】。
  2. 左侧关系树默认选中“华安”，右侧展示该范围内的数据。
  3. 选择活动与筛选条件后，指标卡片、产品维度主表同步刷新。
  4. 点击产品行“查看代理”，在右侧抽屉查看该产品下的代理表现。
  5. 在代理表现中点击“查看客户”，在下一层抽屉查看客户明细。

3. 页面结构

3.1 左侧关系树
  • 展示：代理 + 直客。
  • 默认选中：包含“华安”的节点；若不存在则回退到首个可用节点（Demo 处理）。
  • 选择代理节点：统计该代理及其所有下级代理、直客。
  • 选择直客节点：仅统计该直客。
  • 关系树为空：页面不报错，展示空状态或默认数据。
3.2 顶部筛选区
  • 活动名称（第一筛选项，统计主键）、产品名称（第二筛选项，统计维度）。
  • 活动状态、活动时间。
  • 代理名称 / 客户名称 / MT账号（关键字）。
  • 达标状态。
  • 关系树筛选与顶部筛选按交集展示；切换关系树后保留其它筛选条件。
  • 切换活动后，产品维度主表、代理表现与客户明细同步刷新。
3.3 指标卡片
  • 报名客户数、有效参与客户数、达标客户数、达标率。
  • 活动净入金、交易手数、活跃客户数、奖励/权益发放。
  • 奖励/权益字段：无奖励活动显示“无奖励”；资金奖励显示金额；赠金/体验金显示应发/已释放；实物/资格类显示发放人数或状态。
3.4 产品维度主表
  • 主表按“产品名称”汇总统计当前活动下数据。
  • 字段：产品名称、报名客户数、有效参与客户数、达标客户数、达标率、活动净入金、交易手数、活跃客户数、奖励/权益发放、关联代理数、操作（查看代理）。
  • 选择“全部产品”时展示当前活动下所有产品；选择单个产品时仅展示该产品或同步为该产品统计。
3.5 产品下钻：代理表现（抽屉）
  • 入口：点击产品维度主表的“查看代理”。
  • 字段：代理名称、代理层级、上级代理、伞下符合条件客户数、报名客户数、有效参与客户数、参与率、达标客户数、达标率、活动净入金、交易手数、活跃客户数、操作（查看客户）。
3.6 代理下钻：客户明细（抽屉）
  • 入口：在代理表现中点击“查看客户”。
  • 字段：客户姓名、MT账号、所属代理、产品名称、报名时间、审核通过时间、参与状态、达标状态、达标进度、活动净入金、交易手数、奖励/权益状态、最后更新时间。

4. 业务规则

  • 报名客户数：提交活动报名的客户数。
  • 有效参与客户数：活动审核通过的客户数；审核通过才算参与。
  • 达标客户数：满足当前活动 + 产品规则的有效参与客户数。
  • 未达标客户数：有效参与客户数 - 达标客户数。
  • 达标率：达标客户数 / 有效参与客户数（在当前活动 + 当前产品范围内计算）。
  • 参与率：有效参与客户数 / 伞下符合条件客户数。
  • 代理伞下用户：包含该代理所有下级代理及直客。
  • 一个客户参与多个活动时，仅统计当前选择活动。

5. 字段说明

模块 字段 说明
筛选区 活动名称 统计主键（活动 ID），用于确定当前分析范围。
筛选区 产品名称 当前活动下的统计维度；选择后指标与下钻范围同步切换。
筛选区 代理/客户/MT 关键字命中代理名称、客户名称或 MT 账号。
指标 达标率/参与率 分母为 0 时展示 “-” 或 0%，不能显示 NaN。
客户明细 产品名称 / 达标进度 产品名称用于归属维度；达标进度支持演示：已完成 80%，净入金 8,000 / 10,000，交易 35 / 50 Lot。
奖励/权益 奖励/权益发放 无奖励活动显示“无奖励”；资金/赠金/资格权益按不同类型展示。

6. 交互说明

  • 关系树选择与顶部筛选条件同时存在时，按交集展示。
  • 切换关系树节点后，不清空其它已选筛选条件。
  • 切换活动后，指标、产品维度主表、代理表现、客户明细同步刷新。
  • 点击产品“查看代理”后打开代理表现抽屉；在代理表现中点击“查看客户”后打开客户明细抽屉。

7. 异常提示

  • 有报名但未审核通过：不计入有效参与客户数。
  • 达标率分母为 0：展示 “-” 或 0%，不能显示 NaN。
  • 代理没有伞下客户：指标显示 0，排行榜/明细为空状态。
  • 无奖励活动：奖励字段显示“无奖励”，页面不空白。
  • 选择直客节点：仅展示该直客在当前活动 + 当前产品范围内的数据。

8. Demo 说明

  • 本页面使用演示数据展示筛选与联动效果，不接真实后端接口。
  • 活动达标规则、净入金、交易手数等口径以演示数据为准；真实统计与口径校验仅写入 PRD，不在 Demo 强实现。

9. 验收标准

  • 页面包含关系树、筛选区、指标卡片、产品维度主表、代理表现（抽屉）、客户明细（抽屉）。
  • 默认选中“华安”；选择代理包含所有下级代理与直客；选择直客仅统计当前直客。
  • 筛选条件与关系树按交集生效；切换关系树不清空其它筛选。
  • 无奖励活动可正常展示“无奖励”。
  • 达标率分母为 0 不显示 NaN。
  • 需求看板/业务页面/路由 meta 的 PRD 入口均指向同一份 PRD 主文件，且通过右侧 Drawer 打开。
