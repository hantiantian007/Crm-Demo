1. 需求说明

  • 出入金报表、提现报表、现实持仓报表增加左侧关系树，用于按代理与直客关系筛选报表数据。
  • 关系树与原有筛选条件同时存在时，按交集展示。
  • 页面文案统一使用“演示数据”，不使用 “Mock”。

2. 操作流程

  1. 进入报表页面（出入金 / 提现 / 现实持仓）。
  2. 左侧关系树默认选中“华安”。
  3. 点击代理节点：右侧报表展示该代理及其所有下级代理、直客范围内的数据。
  4. 点击直客节点：右侧报表仅展示该直客的数据。
  5. 在顶部筛选区继续选择筛选条件，与关系树选中范围共同生效（交集）。

3. 页面状态

3.1 通用结构（3 个页面一致）
  • 左侧：关系树（代理 + 直客）。
  • 右侧：顶部筛选区 / 汇总数据区域 / 列表表格。
  • 顶部 PRD 按钮：通过右侧 Drawer 打开本 PRD。
3.2 出入金报表
  • 筛选：类型（入金/出金）、MT账号、系统时间。
  • 汇总：记录数、入金合计、出金合计、净入金。
3.3 提现报表
  • 筛选：MT账号、状态、系统时间。
  • 汇总：记录数、出金合计、待处理、已完成。
3.4 现实持仓报表
  • 筛选：交易品种。
  • 汇总：交易品种数、订单数、浮动盈亏、净头寸。
  • 列表：按交易品种聚合展示（演示聚合逻辑）。

4. 业务规则

  • 关系树默认选中：华安；若默认节点不存在，则回退为第一个可用节点或“全部”（Demo 处理）。
  • 选中代理：查询范围包含该代理及其所有下级代理、直客。
  • 选中直客：仅查询该直客。
  • 关系树选中范围与顶部筛选条件同时存在时：按交集展示。
  • 切换关系树节点后：刷新报表数据，不清空其它已选筛选条件。

5. 字段说明

5.1 关系树节点
  • 节点类型：代理 / 直客。
  • 展示：编号-名称（演示数据）。
5.2 出入金/提现表格字段（演示）
  • 订单号、客户、代理、MT账号、金额(USD)、状态、MT时间、系统时间。
5.3 现实持仓表格字段（演示）
  • 交易品种、净头寸(手)、浮动盈亏(USD)、笔数(BUY/SELL)、买入/价格、卖出/价格。

6. 交互说明

  • 关系树搜索：支持按代理/直客关键字搜索，并支持 MT 账号命中（演示）。
  • 当前选中节点高亮；点击节点立即刷新右侧报表。
  • Desktop / Tablet / Mobile：关系树与报表内容不遮挡，移动端关系树位于内容上方（演示布局）。

7. 异常提示

  • 关系树数据为空：页面不报错，可展示空状态或保持默认数据（演示）。
  • 选中代理但下级无数据：报表展示空状态。
  • 选中直客但无记录：报表展示空状态。

8. Demo 说明

  • 本期 Demo 使用静态演示数据模拟筛选效果，不接真实后端接口。
  • 不实现导出、复杂权限、真实分页等生产能力；如后续需要，以本 PRD 为依据再拆分任务。

9. 验收标准

  • 三个页面均存在左侧关系树，且默认选中“华安”。
  • 选中代理节点：右侧结果包含该代理及其所有下级代理、直客范围数据。
  • 选中直客节点：右侧结果仅展示该直客数据。
  • 关系树筛选与原筛选条件并存时按交集展示，切换关系树不清空已选筛选条件。
  • 页面 PRD 入口、需求看板 PRD 入口统一打开同一份 PRD 主文件。
